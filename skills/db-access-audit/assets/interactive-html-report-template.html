Why This Matters
A client-facing principal can reach data beyond the intended owner, tenant, workspace, or role boundary.
Exploit Scenario
Scenario

A signed-in user changes the requested record identifier and retrieves or modifies another user's scoped data.

Recommended Remediation
Narrow grants and add explicit row/document predicates tied to immutable server-side identity and membership state.
Validation
Run negative tests as an out-of-scope user and verify deny behavior.
